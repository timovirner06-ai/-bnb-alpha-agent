# BNB Alpha Agent

A lightweight Node.js agent designed to monitor BNB price in real-time and trigger alerts based on custom thresholds. This project serves as a foundation for automated trading or notification systems on BNB Chain.

## Features
- Real-time price fetching via Binance API.
- Configurable price thresholds for alerts.
- Lightweight and easy to deploy (runs on Termux or a VPS).

## Prerequisites
- Node.js (v18 or higher)
- NPM

## Installation & Usage
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `node index.js` to start the agent.

## Built With
- Node.js
- Axios
